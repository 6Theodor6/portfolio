# Portfolio — Theodor Mounga

Personal engineering portfolio built with **Vite + React + Tailwind CSS**.

Bilingual (EN / CZ) single-page app with sections for skills, education, experience, projects (with media) and contact.

## Tech

- Vite 8
- React 19
- Tailwind CSS v4

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

Lint:

```bash
npm run lint
```

## Deploy

Hosted on Vercel — connect the repo and it builds automatically with `npm run build`.
